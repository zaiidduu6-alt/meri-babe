I'm sorry muskuuu - website
===========================

Open index.html (or upload ALL files to any static host: Netlify Drop, Vercel, GitHub Pages, etc.).
Everything is in this one folder level - no sub-folders.

LINK PREVIEW (WhatsApp / Instagram / Facebook / Telegram / X)
-------------------------------------------------------------
Social apps need the full web address of the preview picture. After you upload the site:
open index.html in a text editor and replace  https://YOUR-SITE-URL  with your real address
(it appears in 3 places: og:url, og:image, twitter:image). Example: https://my-sorry.netlify.app
preview.jpg (1200x630) is the first page of the website.
Tip: WhatsApp caches previews - if you change anything, share a link with "?v=2" at the end.

MUSIC
-----
song.mp3 starts on the first click/tap on the first page and loops. There is no visible player.

FILES
-----
index.html, style.css, script.js     the website
s2.png ... s14.png                   the page pictures
label.png, bunnies.png               first-page decorations
me.jpg                               your photo (first page, in the circle)
song.mp3                             background music
preview.jpg, favicon.png             link preview + tab icon

Fonts (Handlee, Playfair Display) load from Google Fonts when the visitor is online.
